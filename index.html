Was ist das?

What is this?

Ein MVP zur Auswertung von Stellungnahmen in Schweizer Vernehmlassungen — mit Fokus auf Haltung je Massnahme, Impact und Nähe zur Interpharma-Position. Die Quell-Pipeline liegt in einem privaten Repository; dieser Leitfaden ist öffentlich.

An MVP for analysing stakeholder submissions in Swiss federal consultations — stance per measure, impact, and alignment with Interpharma’s position. The product source is private; this guide is public.

Für wen? Who is it for?
Public-Affairs- und Policy-Teams bei Interpharma, die statt manueller Excel-Sammlungen eine strukturierte, prüfbare Auswertung brauchen.
Public-affairs and policy teams at Interpharma who need structured, reviewable analysis instead of manual spreadsheets.

2 · Pipeline end-to-end

2 · End-to-end pipeline

Nach dem Submit — ohne weitere manuelle Schritte für die Analysekette.

After submit — no further manual steps for the analysis chain.

1 · Collect / Ingest
Uploads und Paste werden normalisiert. Jedes Dokument landet als Textbrief im Dossier; Roh-PDFs werden archiviert.
Uploads and paste are normalised. Each document becomes a text letter in the dossier; raw PDFs are kept.
2 · Parse & OCR
Zuerst digitale Textschicht. Wenn zu wenig Text oder «OCR erzwingen»: ocrmypdf bzw. Seitenrendering + tesseract. macOS: brew install tesseract ocrmypdf poppler (optional tesseract-lang für Deutsch).
Digital text layer first. If too little text or “force OCR”: ocrmypdf or page render + tesseract. macOS: brew install tesseract ocrmypdf poppler (optional tesseract-lang for German).
3 · Massnahmen & Metadaten
Titel, Keywords und Massnahmen werden aus Struktur/Erläuterung abgeleitet. Demo-Massnahmen nur als Fallback.
Title, keywords and measures are inferred from structure/explanatory text. Demo measures only as fallback.
4 · Fedlex / Web (optional)
Fedlex-Ref im Text oder per Suche; Web-Scrape nur wenn aktiviert — sonst reichen die eingespeisten Dokumente.
Fedlex ref from text or search; web scrape only when enabled — otherwise uploaded docs suffice.
5 · Semantic Engine
Chunking → Embedding-Ähnlichkeit (primär BAAI/bge-m3 via Hugging Face) → Stance je Massnahme → Alignment zu Interpharma.
Chunking → embedding similarity (primary BAAI/bge-m3 via Hugging Face) → stance per measure → alignment to Interpharma.
6 · Dashboard embed
analysis.json wird geschrieben und in dashboard.html eingebettet. Ansichten unten.
analysis.json is written and embedded into dashboard.html. Views below.

3 · Analyse-Ansichten

3 · Analysis views

Vier Dashboard-Bereiche — progressive Erklärung.

Four dashboard areas — progressive explanation.

Überblick — Kennzahlen, Review-Flags, Kurzbefund. Einstieg für die Sitzung: «Was wissen wir schon?»

Overview — KPIs, review flags, short findings. Meeting entry point: “What do we know?”

Zustimmung × Impact — Absender im Spannungsfeld Haltung (X) und Einflussgewicht (Y). Schnell sichtbar: wer zählt und wo steht er.

Agreement × impact — actors on stance (X) vs influence weight (Y). Quickly see who matters and where they stand.

Meinungsfreunde — Nähe zur Interpharma-Position (Similarity). Koalitions-Signal, kein Ersatz für juristische Prüfung.

Opinion allies — proximity to Interpharma’s position (similarity). Coalition signal, not a legal review.

Absender-Matrix — Haltung je Massnahme und Absender. Detailtiefe für Bilaterales und Argumentationslinien.

Sender matrix — stance per measure and actor. Detail for bilaterals and argument lines.

4 · How to run

Die Pipeline-Quelle ist privat. Mit Zugang:

Product source is private. With access:

UI
python3 pipeline/serve.py → http://127.0.0.1:8765/new — Text einfügen und/oder PDF hochladen → Analysieren.
CLI

python3 pipeline/run_vernehmlassung.py add --pdf dossier.pdf --run

python3 pipeline/run_vernehmlassung.py add --text letter.txt --run

python3 pipeline/run_vernehmlassung.py add --paste-file body.txt --force-ocr --run

Dependencies
pip install -r requirements.txt (pypdf, pymupdf, Pillow). OCR optional via Homebrew. HF_TOKEN optional für Similarity; sonst Heuristik.
pip install -r requirements.txt (pypdf, pymupdf, Pillow). OCR optional via Homebrew. HF_TOKEN optional for similarity; otherwise heuristics.
Keine Secrets in öffentliche Repos legen. Tokens nur lokal / in privaten CI-Secrets.
Never put secrets in public repos. Tokens stay local or in private CI secrets.
